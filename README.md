# certs_probe

`certs_probe` は、Ettercap 向けに作成した TLS/HTTPS 監視プラグインです。
TCP/UDP の 443 番ポートを対象にし、ClientHello と QUIC の初期シーケンスを解析して、対象ドメイン（SNI）、TLS バージョン、利用されている暗号スイートなどの情報をログ出力します。

このリポジトリには、ソースコード `certs_probe.c` と、事前にビルド済みの共有ライブラリ `ec_certs_probe.so` が含まれています。

## 概要

- HTTPS/TLS のハンドシェイクを監視
- TCP 443 / UDP 443 のトラフィックに対応
- ClientHello の SNI 抽出
- TLS 1.0 ~ 1.3 の判定
- 暗号スイート名の表示
- QUIC の初期パケットから SNI を推定して表示
- Ettercap のフック機構を利用した動的プラグイン構成

## 動作要件

- Ettercap の開発環境
- `ec.h`, `ec_plugins.h`, `ec_packet.h`, `ec_hook.h` などのヘッダ
- C コンパイラ（gcc, clang など）
- Mac/Linux 系環境を前提とした構成

Ettercap のプラグインとして利用する場合は、対象環境に合わせて Ettercap のプラグイン格納先とビルド環境を準備してください。

## ビルド

このリポジトリのソースをビルドするには、Ettercap の開発ヘッダとリンク設定が必要です。例として、一般的には次のような形でコンパイルします。

```bash
gcc -fPIC -shared -o ec_certs_probe.so certs_probe.c \
  -I/usr/include/ettercap
```

実際の include パスや linker オプションは、利用中の Ettercap バージョンや OS 環境に合わせて調整してください。
既存のバイナリをそのまま利用する場合はビルドを省略することもできます。
バージョンアップや再インストールを行った場合は、プラグインを配置し直す必要があります。

## 利用方法

1. Ettercap をセットアップし、対象ネットワークでパケットを監視可能な状態にします。
2. このプラグインを Ettercap のプラグイン読み込み先ディレクトリに配置します。
3. Ettercap を起動し、プラグインがロードされることを確認します。
4. HTTPS / TLS / QUIC の通信が発生すると、ログに情報が出力されます。

プラグイン配置の例

```bash
sudo cp ec_certs_probe.so /usr/lib/ettercap/
```

QUIC の初期パケットに対しては、ドメイン名やバージョンがログに表示されます。

## 注記

- このプラグインは、通信の傍受と解析を前提とした研究・検証用途を想定しています。
- 監視対象のネットワークと運用権限を十分に確認したうえで利用してください。
- 監視対象や利用目的によっては、法的・倫理的・運用上の制約があるため、適用範囲を遵守してください。

## 補足

このプラグインは、ネットワーク解析や TLS ハンドシェイクの確認、学習用途に向けたツールとして作成されています。  
運用環境によっては、利用する時点の Ettercap バージョンや依存ライブラリの差異により、ビルドや読み込み手順が変わる場合があります。
